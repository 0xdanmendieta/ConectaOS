Cómo usar este sitio

Nomenclatura

Cada elemento del sistema tiene un código único. El formato es DOMINIO.PROCESO.ELEMENTO:

CódigoSignificadoEjemplo
CM / MK / DL / OP / FI / GODominio: Comercial, Marketing, Delivery, Operaciones, Finanzas, GobiernoCM = Comercial
P01, P02…Proceso dentro del dominioCM.P03 = Gestión de Pipeline
A01, A02…Actividad dentro del proceso (secuencial)CM.P03.A02 = Pipeline review semanal
E01, E02…Entregable del proceso, con plantilla vinculadaCM.P03.E01 = Acta de Pipeline Review
C01…C10Plantilla de comunicación con clientes (experiencia homogénea)C03 = minuta post-reunión
H01, H02…Handoff entre áreas (ver matriz)H03 = Comercial → Delivery

Cómo leer un proceso

Empieza siempre por la ficha (owner, trigger, métrica). Después el diagrama para entender el flujo, y solo entonces las actividades en detalle. Los enlaces naranjas (CM.P01.E01) llevan a la plantilla lista para copiar. Al final de cada proceso están los handoffs: si tu trabajo termina ahí, el de otra área empieza — cúmplele el criterio de calidad.

Reglas del sistema

Regla 1 — HubSpot es vinculanteLo que no está en HubSpot no existe. Toda reunión, nota, task y deal se registra el mismo día.
Regla 2 — Toda reunión deja huellaMínimo 3 bullets el mismo día: qué pasó, qué se acordó, cuál es el next step con fecha y dueño.
Regla 3 — Los procesos se ejecutan, no se debatenSi un proceso no funciona, se ejecuta como está y se propone el cambio en la revisión mensual de Gobierno. No se improvisa en el deal.
Regla 4 — Los handoffs tienen criterio de calidadEl receptor puede (y debe) rechazar un handoff incompleto. Un handoff rechazado no es conflicto: es el sistema funcionando.
Regla 5 — Ningún fabricante se vende sin certificaciónNadie vende un producto sin pasar el assessment de CM.P01. Vender sin saber quema leads.

Gestión del cambio del propio OS

Conecta OS es un producto vivo con dueño: el CEO (interino) hasta nombrar un responsable de Operaciones/PMO. Los cambios se proponen por escrito (qué proceso, qué cambia, por qué, evidencia), se revisan en la reunión mensual de Gobierno y se versionan en este sitio. Versión actual: v3.0 — Julio 2026.
